备份合并操作指南

跨设备同步对话记录，合并而非覆盖——在电脑B上安全导入电脑A的对话

使用场景

多设备对话合并

你在电脑A上使用 DeekrStudio 进行了对话，之后在电脑B上也进行了一些对话。现在你希望在电脑B上导入电脑A的对话记录，但不想覆盖电脑B已有的对话。

DeekrStudio 的「从备份导入（合并对话）」功能正是为此设计——它只新增不存在的对话，已有数据完全不受影响。

1

在电脑A上创建备份

  1. 打开 DeekrStudio，进入 设置 → 数据设置 → 数据目录
  2. 点击「备份」按钮，创建备份 ZIP 文件
  3. 将生成的备份文件传输到电脑B（通过 U盘、网盘、微信、邮件等方式）
2

在电脑B上打开导入功能

  1. 打开 DeekrStudio，进入 设置 → 数据设置 → 导入外部应用数据
  2. 找到「从备份导入（合并对话）」选项
  3. 点击右侧的「导入备份文件」按钮

  1. 在弹出的「从备份导入」对话框中，找到上传区域

4

预览并选择要合并的对话

  1. 上传完成后，系统会自动解析备份文件并显示预览列表
  2. 勾选你想要合并的对话（默认全选）
  3. 已存在的对话会自动标记跳过，不会重复导入
  4. 确认后点击「导入」按钮开始合并

📋 注意事项

  • 合并导入只会新增不存在的对话，不会覆盖已有数据
  • 如果两台电脑有相同的对话（相同 ID），会自动跳过
  • 建议在合并前先在电脑B上做一次本地备份，以防万一
  • 备份文件必须是 DeekrStudio 导出的 .zip 格式
